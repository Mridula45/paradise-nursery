# Paradise Nursery Shopping Application 🌿

A responsive online plant shop built with React, Vite, Redux Toolkit, and React Router.

## Features
- Landing page with company introduction and Get Started button
- Three plant categories with six plants per category (18 products total)
- Product cards with image, name, description, and price
- Redux-powered shopping cart with add, increment, decrement, and remove actions
- Dynamic cart badge and item subtotals / grand total
- Shared navigation across Home, Plants, and Cart pages
- Checkout placeholder message and Continue Shopping link

## Run locally
1. Install Node.js (LTS).
2. Extract this project folder.
3. Open a terminal inside the `paradise-nursery` folder.
4. Run:
   ```bash
   npm install
   npm run dev
   ```
5. Open the local URL printed by Vite (usually http://localhost:5173).

## Publish to GitHub
Create a public GitHub repository named `paradise-nursery`, then upload the contents of this folder (not the outer ZIP file). Ensure the `src` folder is included. GitHub file URLs can then be copied from each file's page.
